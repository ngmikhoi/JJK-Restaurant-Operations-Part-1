# Assignment 1 - JJK-Restaurant-Operations-Part-1 
**Course:** Data Structures and Algorithms (CO2003)

## Overview  
This assignment involves implementing a **circular doubly linked list** to manage seating arrangements in a restaurant.

## Tasks  
- Implement a **circular doubly linked list** to represent restaurant seats.  
- Each node stores:  
  - **NAME**: Customer’s name (alphabetic string, case-sensitive, no spaces).  
  - **ENERGY**: An integer representing the energy level.  
- Support operations such as **insertion, deletion, and traversal**.  
- Ensure **no memory leaks** by properly managing dynamic memory allocation.
